# Listing Google Play Store: Firewall AmniGuard

## Nama Aplikasi (27 / 30)

AmniGuard: Firewall No Root

## Deskripsi Singkat (68 / 80)

Blokir internet per aplikasi, saring domain & hemat data tanpa root.

## Deskripsi Lengkap

AmniGuard Firewall menyediakan cara mudah dan canggih untuk mengontrol akses internet serta memblokir konten web di Android — tanpa memerlukan akses root.

Atur aplikasi dan domain mana saja yang boleh mengakses Wi-Fi, data seluler, atau koneksi latar belakang. Lindungi perangkat dari koneksi yang tidak diinginkan, hemat kuota data, dan perpanjang masa pakai baterai dengan privasi total.

--------------------------------------------------

FITUR UTAMA
--------------------------------------------------

• Mudah Digunakan: Antarmuka Material 3 modern dengan tema gelap dan terang.
• Tanpa Root: Beroperasi lokal menggunakan antarmuka VpnService standar Android.
• 100% Sumber Terbuka (Open Source): Transparan, terverifikasi, dan didukung komunitas.
• Nol Telemetri: Tanpa pelacak, tanpa analitik pihak ketiga, dan tanpa pengiriman data keluar.
• Pemrosesan 100% Lokal: Pemeriksaan paket dan aturan DNS berjalan sepenuhnya di perangkat Anda.
• Kontrol Jaringan per Aplikasi: Izinkan atau blokir Wi-Fi dan data seluler untuk setiap aplikasi secara terpisah.
• Hemat Baterai & Kuota Data: Cegah kebocoran data di latar belakang dan hemat penggunaan kuota.
• Dukungan Protokol Lengkap: Pemfilteran menyeluruh untuk IPv4, IPv6, TCP, UDP, dan ICMP.
• Filter Layar Aktif & Roaming: Batasi koneksi saat layar terkunci atau saat roaming.
• Kontrol Aplikasi Sistem: Kelola aplikasi pengguna dan aplikasi sistem bawaan.
• Dukungan Hotspot / Tethering dan jaringan lokal LAN.

--------------------------------------------------

PEMFILTERAN DOMAIN & KONTEN LOKAL
--------------------------------------------------

• Perlindungan Situs Dewasa: Pemblokiran DNS lokal instan tanpa latensi untuk 80.000+ domain eksplisit.
• Pemblokir Gangguan & Media Sosial: Blokir platform yang mengganggu fokus sesuai jadwal.
• Aturan Kustom: Tambahkan daftar hitam, daftar putih, dan aturan wildcard (*.example.com) langsung di aplikasi.
• Pencegahan Kebocoran DoT: Menghentikan upaya bypass DNS terenkripsi untuk menjaga keamanan aturan.

--------------------------------------------------

DIAGNOSTIK & ALAT PRO
--------------------------------------------------

• Log Lalu Lintas Langsung: Periksa koneksi keluar lengkap dengan IP tujuan, port, dan nama host.
• Ekspor Paket PCAP: Ekspor lalu lintas jaringan untuk analisis mendalam di Wireshark.
• Grafik Kecepatan Real-Time: Tampilkan kecepatan dan statistik jaringan di bilah notifikasi.
• Notifikasi Akses Cepat: Dapatkan peringatan instan saat aplikasi baru mencoba terhubung.

--------------------------------------------------

PRIVASI & TRANSPARANSI
--------------------------------------------------

AmniGuard menggunakan API VpnService Android semata-mata sebagai filter loopback lokal di perangkat Anda. Tidak ada data jaringan yang pernah dikirim ke server jarak jauh atau pihak ketiga.
